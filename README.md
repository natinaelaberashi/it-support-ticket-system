# Transaction Processing & Operations Analytics

A portfolio project focused on transaction volumes, failure patterns, SLA performance and operational impact.

## Skills demonstrated
- SQL aggregation and filtering
- KPI and SLA analysis
- Failure-rate calculation
- Root-cause-oriented operational analysis
- Translating transaction data into management insights

## Files
- data/transactions.csv — synthetic transaction dataset
- sql/analysis.sql — reusable analysis queries
- insights.md — example findings and recommendations

All data is synthetic and created for portfolio demonstration.
